# Инструкция по использованию Document KVP Lab

## Назначение

Приложение предназначено для магистерской работы по извлечению значений и координат из документов. Пользователь загружает документ, выбирает страницу, вводит нужный ключ, а модель возвращает значение и bbox, где это значение находится.

Ожидаемый формат ответа модели:

```text
<|ref|>text<|/ref|><|det|>[[x1,y1,x2,y2]]<|/det|>value
```

Координаты bbox нормализованы в диапазон `0..999`, как в `train.py`.

## Структура проекта

- `app/` - FastAPI backend и статический frontend.
- `checkpoint-1/` - LoRA-адаптер.
- `deepseek_ocr/` - базовая модель DeepSeek-OCR.
- `data/documents.sqlite3` - SQLite база.
- `data/uploads/` - исходные загруженные файлы.
- `data/pages/` - изображения отдельных страниц.
- `scripts/evaluate_kvp10k.py` - оценка чекпоинта на подготовленном KVP10k.

## Запуск

Сервер запускается так:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Открыть:

```text
http://127.0.0.1:8000
```

## Как пользоваться

1. Нажать `Upload document`.
2. Загрузить изображение или PDF.
3. Если это PDF, приложение разобьет его на страницы.
4. Выбрать документ слева.
5. Выбрать страницу через вкладки `Page 1`, `Page 2` и так далее.
6. В поле `Key to find` ввести ключ, например `Invoice Number`.
7. Нажать `Extract page`, чтобы искать ключ только на текущей странице.
8. Нажать `Extract all pages`, чтобы искать этот ключ на всех страницах документа.
9. Результаты сохраняются отдельно: ключ, найденное значение, bbox и raw output модели.

## Редактирование

В интерфейсе доступны:

- переименование документа;
- удаление документа;
- изменение номера страницы;
- удаление страницы;
- удаление отдельного результата extraction.

Backend также поддерживает редактирование extraction через `PATCH /api/extractions/{id}`.

## Оценка на KVP10k

Скрипт ожидает такую же подготовленную структуру, как использовалась в `train.py`:

```text
KVP10k/test/gts/*.json
KVP10k/test/images/*.jpg|*.png
```

Пример короткого запуска:

```powershell
.\.venv\Scripts\python.exe scripts\evaluate_kvp10k.py --gts KVP10k\test\gts --images KVP10k\test\images --limit 10
```

Метрики:

- `parse_success_rate` - доля ответов, где удалось получить значение;
- `value_exact_accuracy` - точное совпадение значения после нормализации текста;
- `value_similarity_mean` - средняя похожесть текста через SequenceMatcher;
- `bbox_iou_mean` - средний IoU bbox;
- `bbox_iou_50_accuracy` - доля bbox с IoU >= 0.5.

На RTX 2060 полный прогон KVP10k будет очень долгим. Сначала используйте `--limit 5` или `--limit 10`.
